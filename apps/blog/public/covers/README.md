# Blog covers

Generated using the controls and PNG export in https://github.com/zolplay-labs/fluid-gradient-studio at commit `0f4b4eaa5dfe6314699f213a4dccad99e3d1b4b6`.

Each cover uses the included Knowhere logo in black (`#111111`) and a separately randomized composition. The title is empty and the Text layer is disabled. Both content gradient stops have 0% opacity. Export settings: 4:3, 2K PNG, default pixel effect. PNG exports are converted with cwebp (quality 88) to 1200 × 900 WebP. Filenames match article slugs.

Colors are set directly in the generator controls using the Knowhere green palette and neutral Mist White. Diffusion, Stripes, and Particle Flow use one base color; Liquid Marble uses three.
