按钮 Button

黑底用于主要操作，白底用于次要操作。两种按钮共用高度、圆角和文字层级，保持稳定的布局占位。

尺寸

共同参数：圆角 2 · 描边 1 · 字重 500L 沿用 Login；M / S 为扩展建议
尺寸高度字号 / 行高水平内边距图标 / 间距适用位置
L 大号 现有4615 / 2413加载图标 16；白 11 / 黑 13Login 表单主次操作
M 中号 建议4014 / 2012建议 16 / 8常规表单、工具栏
S 小号 建议3213 / 2010建议 16 / 6桌面紧凑操作

状态

  • 状态优先：加载 / 禁用阻止交互；按下覆盖悬停；键盘焦点轮廓可与可用状态叠加。
  • 加载：disabled + aria-busy；保留默认配色，16px 转圈图标，800ms / 圈，宽高不变。减少动态效果时停止旋转。
  • 操作结果：由表单显示成功或错误反馈，不将按钮长期改成红色或绿色。

状态

  • 优先级：禁用 → 聚焦 → 错误 → 悬停 → 默认。错误时聚焦仍为绿色描边，红色辅助文本保留。
  • 只读：可聚焦、选择、复制，不能编辑；禁用：不可编辑、不进入键盘 Tab 顺序、无悬停反馈。
  • 自动填充：与已填写状态一致；用白色内嵌覆盖层消除浏览器默认填充色，不叠加外描边。上方为外观示意，真实自动填充由浏览器触发。

沿用 SDK 示例的矩形 Tab：选中项矿物绿实底、白字，未选中项透明底、绿色描边。组件圆角为 2px。

默认、悬停、选中来自 SDK 源码；焦点沿用项目 2px 外轮廓，间隔 2px 为本页建议；按下、禁用为复用表单 token 的补充建议。未定义独立加载态：异步数据加载应出现在对应内容面板中。

禁用项的面板不参与切换。

Ruby 仅用于禁用态演示，不代表产品计划支持。点击切换不移动整组的位置。

  • 键盘：Tab 进入当前选中项；← / → 循环切换；Home / End 定位首尾；禁用项跳过。
  • 语义：本页演示使用 tablist / tab / tabpanel；aria-selected 表示选中，aria-controls 关联内容，非当前 Tab 的 tabindex 为 −1。
  • 移动端：26px 是 SDK 局部视觉高度。若扩展到一般触摸界面，建议在不改变视觉高度的情况下扩大点击区域，避免直接复用为紧凑的触摸目标。
现有实现边界　SDK 当前使用普通按钮、is-active 与 aria-pressed 切换，尚未实现本页演示的完整 Tab 键盘语义；Landing 的旧代码示例已存在方向键 / Home / End 逻辑。本页补全交互展示，未宣称线上 SDK 已具备这些行为。Tab 高度还受页面断点的 min-height 覆盖，本页按 DESIGN.md 的 44 / 26 展示。
